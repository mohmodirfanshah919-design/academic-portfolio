# Zuha Kanji — Geotechnical Engineer Portfolio

Responsive static academic and professional website.

## Files
- `index.html`: website structure and content
- `styles.css`: design, typography, colours, responsive layout
- `script.js`: mobile navigation and current year

## Important before publishing
- Review every detail, especially the publication record, internship descriptions, and profile links.
- Date of birth has intentionally been omitted from the public website. A birth date is generally unnecessary on a professional portfolio.
- The supplied CV included a phone number and membership number; these have been omitted from the public website for privacy.
- The publication listed is a preliminary entry from an online search. Verify the publisher record and DOI before promoting the site.
- Add the correct Google Scholar and ORCID links when available.
- Do not upload the full CV publicly without reviewing personal information first.

## Publish with Vercel
Upload the three site files (`index.html`, `styles.css`, `script.js`) and this README to the root of a GitHub repository. Import that repository into Vercel. Choose framework preset `Other`; leave the build command blank and set the output directory to `.` if Vercel asks.
