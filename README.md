# Zuha Kanji — Interactive Academic & Engineering Portfolio

A responsive, static website with a navy/ivory/gold visual system, animated hero, responsive navigation, theme toggle, scroll reveal effects, searchable/filterable publications, expandable abstracts, DOI/publisher links, and an interactive Three.js conceptual geotechnical model.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design, responsive layouts and animations
- `script.js` — interactions and Three.js model

## Publish with GitHub + Vercel
1. Download and extract this ZIP on your computer.
2. Open your existing GitHub repository for `academic-portfolio`.
3. Choose **Add file → Upload files**.
4. Upload these four files from the extracted folder, replacing files with the same names: `index.html`, `styles.css`, `script.js`, and `README.md`.
5. Commit the changes to the branch connected to Vercel.
6. In Vercel, open the latest deployment and wait for **Ready**. Then test your domain.

## Important notes
- This is a **static website**; no server or database is required.
- The 3D model loads Three.js from jsDelivr, so an internet connection is required for the full 3D experience. If it cannot load, a simple fallback illustration is shown.
- The 3D scene is a **conceptual visualisation only**. The sliders alter visual appearance and do not calculate validated engineering results.
- DOI/publisher links open the publishers' pages. Access or purchase options are controlled by the publishers; free full-text access is not guaranteed.
- Review professional details and publication metadata before publishing. No phone number, date of birth, or portrait is included.
